# Monitoring roadmap

The first increment delivers Nexus-managed ICMP devices plus authenticated SigNoz API connectivity. Planned increments are:

1. Validate the deployed SigNoz alert-rule API schema and manage the Device Unreachable alert from Nexus.
2. Surface current ICMP loss/latency from SigNoz in the Nexus device table.
3. Add HTTP/HTTPS and TCP synthetic profiles.
4. Add SNMP profiles for network equipment where useful.
5. Correlate guest monitoring identity with PDM remote/type/VMID and provide maintenance suppression from power workflows.
